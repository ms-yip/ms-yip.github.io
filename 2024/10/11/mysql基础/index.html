修改root密码

确保mysql是关闭状态

1、 进入mysql文件夹，终端输入： cd /usr/local/mysql/bin 点击回车；

2、获取权限，输入： sudo su 点击回车，输入电脑开机密码，点击回车；（此时输入的密码终端是看不到的，根据记忆输入即可）；

3、进入安全模式，输入： ./mysqld_safe –skip-grant-tables & 点击回车。

三、再次启动一个新的终端（之前那个放着不动）
1、进入mysql命令模式，终端输入：mysql 点击回车；

2、终端内输入：use mysql点击回车；

3、设置root账户为空密码，终端内输入：UPDATE user SET authentication_string=’’ where user=’root’; 点击回车；

4、刷新权限：flush privileges; 点击回车；

5、退出 exit 。

四、设置新密码
1、进入mysql，终端输入：mysql -uroot -p 点击回车，输入密码时，直接回车；

2、进入mysql数据库，输入：use mysql 点击回车；

3、设置新密码，输入 alter user ‘root’@’localhost’ identified by ‘你期望的新密码’; 点击回车；

4、刷新权限，输入：flush privileges; 回车。

序号 通配符类型 描述 SQL 示例
1 百分号通配符 % 表示零个或多个字符。例如，'a%' 匹配以字母 'a' 开头的任何字符串。 SELECT * FROM customers WHERE last_name LIKE 'S%';
2 下划线通配符 _ 表示一个字符。例如，'_r%' 匹配第二个字母为 'r' 的任何字符串。 SELECT * FROM products WHERE product_name LIKE '_a%';

ORDER BY(排序) 语句

ASC 表示升序（默认），DESC 表示降序。

序号 排序类型 SQL 示例 描述
1 单列排序 SELECT * FROM products ORDER BY product_name ASC; 选择 products 表中的所有产品，并按 product_name 升序排序。
2 多列排序 SELECT * FROM employees ORDER BY department_id ASC, hire_date DESC; 选择 employees 表中的所有员工，先按 department_id 升序排序，再按 hire_date 降序排序。
3 使用数字表示列的位置 SELECT first_name, last_name, salary FROM employees ORDER BY 3 DESC, 1 ASC; 选择 employees 表中的 first_name、last_name 和 salary 列，并按第三列（salary）降序排序，再按第一列（first_name）升序排序。
4 使用表达式排序 SELECT product_name, price * discount_rate AS discounted_price FROM products ORDER BY discounted_price DESC; 选择 products 表中的 product_name 和计算后的 discounted_price，并按 discounted_price 降序排序。
5 处理 NULL 值 SELECT product_name, price FROM products ORDER BY price DESC NULLS LAST; 选择 products 表中的 product_name 和 price，并按 price 降序排序，将 NULL 值排在最后。
5 处理 NULL 值 SELECT product_name, price FROM products ORDER BY price DESC NULLS FIRST; 选择 products 表中的 product_name 和 price，并按 price 降序排序，将 NULL 值排在最前。
6 添加 WHERE…LIKE 子句来设置条件 SELECT employee_id,first_name,last_name,department_id, salary, hire_date FROM employees WHEREdepartment_id IN (10, 20, 30)AND first_name LIKE 'J%'AND salary IS NOT NULLORDER BY department_id ASC,salary DESC NULLS LAST,hire_date ASC; 从 employees 表中筛选特定部门、名字以 ‘J’ 开头且工资不为 NULL 的员工，并按部门、工资和雇佣日期进行排序的功能。
7 COUNT、SUM、AVG SELECT department, AVG(salary) AS avg_salary FROM employees GROUP BY department; 统计每个部门的平均工资

MySQL NULL 值处理

类型 说明 用法示例 注意事项
运算符
IS NULL 判断列值是否为 NULL SELECT * FROM employees WHERE department_id IS NULL; 不可用 = NULL 替代（NULL = NULL 返回 NULL，而非 TRUE）
IS NOT NULL 判断列值是否不为 NULL SELECT * FROM employees WHERE department_id IS NOT NULL; 不可用 != NULL 替代
<=> 安全等于运算符，比较两个值（包括 NULL）是否相等 SELECT * FROM employees WHERE commission <=> NULL; 唯一能正确比较 NULL = NULL 的运算符，返回 TRUE
函数
IFNULL() 若第一个参数为 NULL，返回第二个参数 SELECT product_name, IFNULL(stock_quantity, 0) FROM products; 仅接受两个参数，MySQL 特有
COALESCE() 返回参数列表中第一个非 NULL 值 SELECT product_name, COALESCE(stock_quantity, 0, 100) FROM products; 可接受多个参数，标准 SQL 函数
排序
ORDER BY 默认 NULL 值在排序时排在最后 SELECT * FROM products ORDER BY price ASC; 若需 NULL 值在前，使用 ORDER BY price ASC NULLS FIRST（MySQL 8.0+ 支持）
聚合函数
COUNT() 统计非 NULL 值的数量 SELECT COUNT(name) FROM employees; COUNT(*) 统计所有行，包含 NULL 列
SUM()/AVG() 忽略 NULL 值进行计算 SELECT AVG(COALESCE(salary, 0)) FROM employees; 若需将 NULL 视为 0，需显式使用 COALESCE 或 IFNULL
注意事项
条件比较 WHERE column = NULL 永远无效，必须用 IS NULL 错误示例：SELECT * FROM table WHERE column = NULL; 所有与 NULL 的比较（如 >, <, =）均返回 NULL，而非 TRUE/FALSE
表设计 设计表时，明确是否需要允许 NULL（如非必要，可设置 NOT NULL 并指定默认值） CREATE TABLE users (id INT NOT NULL, name VARCHAR(50) DEFAULT 'Anonymous'); 合理使用 DEFAULT 约束减少 NULL 值
函数兼容性 COALESCE 是标准 SQL 函数，IFNULL 是 MySQL 特有 跨数据库兼容建议优先使用 COALESCE IFNULL 仅支持两个参数，COALESCE 支持多参数

MySQL 正则表达式核心语法表

分类 模式/操作符 描述 示例 注意事项
基本操作符 REGEXP 或 RLIKE 正则匹配操作符 SELECT * FROM table WHERE column REGEXP 'pattern'; REGEXP 和 RLIKE 完全等价，可互换使用
定位符 ^ 匹配字符串开头 WHERE name REGEXP '^st' → 以 “st” 开头的字符串 多行模式下 (m) 可匹配换行符后位置（MySQL 默认不支持多行模式）
$ 匹配字符串结尾 WHERE name REGEXP 'ok$' → 以 “ok” 结尾的字符串
通配符 . 匹配任意单个字符（除换行符） WHERE name REGEXP 'a.b' → 匹配 “aXb”、”a5b” 等 如需包含换行符，需使用 [.\n]
字符集合 [...] 匹配括号内任意字符 WHERE name REGEXP '[aeiou]' → 包含任意元音字母的字符串 区分大小写（除非使用 BINARY 或设置大小写不敏感）
[^...] 匹配不在括号内的任意字符 WHERE name REGEXP '[^0-9]' → 包含非数字字符的字符串
量词 * 匹配前一个元素 0 次或多次 WHERE name REGEXP 'zo*' → 匹配 “z”、”zoo”
+ 匹配前一个元素 1 次或多次 WHERE name REGEXP 'zo+' → 匹配 “zo”、”zoo”，但不匹配 “z”
{n} 精确匹配前一个元素 n 次 WHERE name REGEXP 'o{2}' → 匹配 “food” 中的 “oo”
{n,m} 匹配前一个元素至少 n 次，最多 m 次 WHERE name REGEXP 'o{1,3}' → 匹配 “book”、”foooood”
逻辑或 ` ` 匹配多个模式之一 `WHERE name REGEXP ‘Smith Johnson’` → 匹配 “Smith” 或 “Johnson” 可用括号分组：`(a b)c` → “ac” 或 “bc”
字符类 \d 或 [0-9] 匹配数字字符 WHERE name REGEXP 'item\\d+' → 匹配 “item1”、”item20” MySQL 中需双写反斜杠：\\d
\w 匹配字母、数字或下划线（等同于 [a-zA-Z0-9_]） WHERE name REGEXP '\\w{5}' → 匹配5位字母数字组合
\s 匹配空白字符（空格、制表符、换行符等） WHERE text REGEXP '\\s+' → 匹配包含空白符的字符串
特殊功能 BINARY 区分大小写匹配 WHERE name REGEXP BINARY 'Apple' → 仅匹配大写的 “Apple” 默认不区分大小写（依赖数据库配置）
复杂示例 - 组合使用 `WHERE name REGEXP ‘^[aeiou] ok$’` → 以元音开头或以 “ok” 结尾的字符串 使用括号明确优先级：`^(abc def)`

注意事项

  1. 性能影响：正则表达式匹配比简单字符串匹配（如 LIKE）更消耗资源，避免在大数据表频繁使用。
  2. 转义字符：MySQL 中需用双反斜杠（\\）转义特殊字符（如 \\d 表示数字）。
  3. 大小写敏感：默认不区分大小写，如需区分需显式使用 BINARY 关键字。
  4. 部分功能限制：不支持某些高级正则特性（如回溯引用、零宽断言）。

通过合理使用正则表达式，可以高效完成复杂文本匹配任务，但需注意其适用场景和性能影响。

事务

事务是必须满足4个条件（ACID）：：原子性（原子性，或称分割性）、一致性（一致性）、隔离性（隔离性，行为独立性）、持久性（持久性）

MYSQL事务处理主要有两种方法：

1、用BEGIN、ROLLBACK、COMMIT来实现

  • BEGIN 或 START TRANSACTION：开用于开始一个事务。
  • ROLLBACK事务回滚，取消之前的更改。
  • COMMIT：事务确认，提交事务，使更改永久生效。

2、直接用SET来改变MySQL的自动提交模式：

  • SET AUTOCOMMIT=0 禁止自动提交
  • SET AUTOCOMMIT=1开启自动提交

MySQL ALTER 命令操作汇总表

当我们需要修改数据表名或者修改数据表字段时，就需要使用到 MySQL ALTER 命令。

MySQL 的 ALTER 命令用于修改数据库、表和索引等对象的结构。

ALTER 命令允许你添加、修改或删除数据库对象，并且可以用于更改表的列定义、添加约束、创建和删除索引等操作。

ALTER 命令非常强大，可以在数据库结构发生变化时进行灵活的修改和调整。

分类 操作类型 语法 示例 注意事项
列操作 添加列 ALTER TABLE 表名 ADD COLUMN 列名 数据类型 [约束]; ALTER TABLE employees ADD COLUMN birth_date DATE; 添加列时建议指定默认值或允许 NULL，避免现有数据冲突
修改列数据类型 ALTER TABLE 表名 MODIFY COLUMN 列名 新数据类型; ALTER TABLE employees MODIFY COLUMN salary DECIMAL(10,2); 修改数据类型可能导致数据截断（如 VARCHAR 长度减少）
重命名列 ALTER TABLE 表名 CHANGE COLUMN 旧列名 新列名 数据类型; ALTER TABLE employees CHANGE COLUMN old_name new_name VARCHAR(255); 必须同时指定新列的数据类型
删除列 ALTER TABLE 表名 DROP COLUMN 列名; ALTER TABLE employees DROP COLUMN birth_date; 删除列会永久丢失数据，操作前需备份
键约束 添加主键 ALTER TABLE 表名 ADD PRIMARY KEY (列名); ALTER TABLE employees ADD PRIMARY KEY (employee_id); 主键列必须为 NOT NULL 且唯一
添加外键 ALTER TABLE 子表 ADD CONSTRAINT 约束名 FOREIGN KEY (列名) REFERENCES 父表 (列名); ALTER TABLE orders ADD CONSTRAINT fk_customer FOREIGN KEY (customer_id) REFERENCES customers (customer_id); 外键列和父表列数据类型必须一致，且父表列需为唯一约束或主键
表操作 重命名表 ALTER TABLE 旧表名 RENAME TO 新表名; ALTER TABLE employees RENAME TO staff; 表名修改后，相关视图、存储过程需同步更新
修改表字符集 ALTER TABLE 表名 CONVERT TO CHARACTER SET 字符集; ALTER TABLE employees CONVERT TO CHARACTER SET utf8mb4; 转换字符集可能影响现有数据的存储，需谨慎操作
索引操作 添加索引 ALTER TABLE 表名 ADD INDEX 索引名 (列名); ALTER TABLE employees ADD INDEX idx_name (last_name); 可为单列或多列创建索引，提升查询性能
删除索引 ALTER TABLE 表名 DROP INDEX 索引名; ALTER TABLE employees DROP INDEX idx_name; 删除索引可能影响查询性能
其他操作 设置自增初始值 ALTER TABLE 表名 AUTO_INCREMENT = 初始值; ALTER TABLE employees AUTO_INCREMENT = 1000; 仅适用于包含 AUTO_INCREMENT 列的表
添加表注释 ALTER TABLE 表名 COMMENT '注释内容'; ALTER TABLE employees COMMENT '员工信息表'; 注释内容需用引号包裹

关键注意事项

  1. 性能影响：
    • ALTER TABLE 可能触发表重建（如修改列类型、添加主键），对大表操作时会导致锁表，建议在低峰期执行。
    • 使用 ALGORITHM=INPLACE 或 ALGORITHM=COPY 可控制重建方式（需存储引擎支持）。
  2. 数据安全：
    • 执行 DROP COLUMN、RENAME TABLE 等高风险操作前，务必备份数据。
  3. 外键约束：
    • 添加外键时需确保父表存在且列匹配，否则操作失败。
  4. 兼容性：
    • 修改表结构可能导致应用程序兼容性问题（如字段名或类型变更）。

GROUP_CONCAT : 是 MySQL 中的一个聚合函数，它将分组后的多行数据合并成一个字符串，通常用于需要将多行数据拼接成单行结果的场景。
