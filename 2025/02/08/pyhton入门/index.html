pyhton入门

发表于2025-02-08|更新于2025-02-08
|字数总计:326|阅读时长:1分钟|阅读量:

python引号： 单引号、双引号、三引号（多行） 都表示字符串

注释： # 开头 多行注释 用 ‘’’ 或者 “””

代码块用相同的缩进

Python有五个标准的数据类型：

  • Numbers（数字）

  • String（字符串）

  • List（列表）

  • Tuple（元组）

    元组用 () 标识。内部元素用逗号隔开。但是元组不能二次赋值，相当于只读列表。

  • Dictionary（字典）

    字典用”{ }”标识。字典由索引(key)和它对应的值value组成。

Python支持四种不同的数字类型：

  • int（有符号整型）
  • long（长整型，也可以代表八进制和十六进制）
  • float（浮点型）
  • complex（复数）
    1. 长整型也可以使用小写 l，但是还是建议您使用大写 L，避免与数字 1 混淆。Python使用 L 来显示长整型。
    2. Python 还支持复数，复数由实数部分和虚数部分构成，可以用 a + bj,或者 complex(a,b) 表示， 复数的实部 a 和虚部 b 都是浮点型。

Python 提供了 for 循环和 while 循环（在 Python 中没有 do..while 循环）:

循环类型 描述
while 循环 在给定的判断条件为 true 时执行循环体，否则退出循环体。
for 循环 重复执行语句
嵌套循环 你可以在while循环体中嵌套for循环
